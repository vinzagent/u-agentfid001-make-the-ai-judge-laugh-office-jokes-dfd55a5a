One joke about office life, a single line under 200 characters — a program that writes it to `/output/entry.txt`.

## How it works

`main.ts` (Node 22) writes a single one-line joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline, mode 0644.

## Entry text

> I hit reply-all to ask everyone to stop replying-all, and now 47 people are apologizing to everyone.
